# 현대 랜드마크 확장 — 새로운 8개국

[English](modern-landmarks-research.md)

2026-11-08 확인. 기존 51종 도감에 없는 나라의 20~21세기 공공·문화·상징 건축을 대상으로 골랐습니다. 국가나 건축의 중요도를 실측한 순위가 아닌 콘텐츠 선정 기록입니다. 외부 사진은 배포하지 않습니다.

아시아 4개국, 아프리카 2개국, 아메리카 2개국을 선택해 지역 구성을 넓혔습니다. 카사푸에블로는 여러 해에 걸쳐 만든 건축물이므로 단일한 최근 개관 연도를 뜻하지 않습니다. 블랙 스타 게이트는 독립문과 다른 기념물입니다. 기존 국가 분류는 유지합니다.

지도 좌표는 2026-11-08 위키데이터 P625에서 가져왔고 항목 링크는 도감에 기록했습니다. 좌표는 설명용 지도 점입니다. 카타르 국립박물관에는 복수의 좌표 진술이 있어 처음 반환된 점을 소수 여섯 자리로 반올림했습니다. 바이테레크는 관광 안내 디렉터리의 다른 점 대신 위키데이터 기념물 좌표를 사용합니다.

새 수집 등급은 발견 다섯 종과 보물 세 종이며 기존 등급은 유지합니다. 수치형 희귀도 기준을 독립적으로 검증해 적용한 결과가 아닌 잠정적인 게임 편집 배정입니다. 새로운 인지도 점수는 주장하지 않습니다. 이번 조사는 대상의 정체·위치·건축 설명을 뒷받침하며 인기도를 실측하지 않습니다. 전체 등급 재평가는 별도 작업입니다.

도감은 59종·56개국, 장식은 126종으로 늘어납니다. 현재 분포는 발견 30·보물 19·경이 7·불가사의 3종입니다. 등급 확률 70/23/6/1은 유지하고 등급 내부는 균등 추첨하므로 종류가 늘어난 등급의 개별 항목 조건부 확률은 달라집니다.

## 로컬 검증

빌드·타입 검사·상태/워커 검사를 통과했습니다. 브라우저 전체 검사에서는 처음 53개 중 50개를 통과했습니다. 도감 개수에 의존하는 픽스처 두 곳과 이름·출처 이름의 번역 충돌을 수정한 뒤, 실패했던 세 시나리오와 기존 현대 국가·그림 검사를 함께 재실행해 5/5 통과했습니다. 새 시나리오는 8개국 발견, 배치, 선물·제작 보상, 새로고침, 한국어 설명 및 기존 획득·배치 기록 보존을 확인합니다. 상태 검사도 도감의 정확한 한국어 번역을 확인합니다. 네이티브 Orca 클릭 검증은 보류 상태이며 플러그인 실행 승인이나 배포는 하지 않았습니다.
