## 등급 배정과 호환성

발견 5종·보물 3종은 게임을 위한 잠정 편집 배정입니다. 공식 유산 등급이나 수치화된 인지도 점수를 독립적으로 검증한 결과가 아닙니다. 조사는 명소의 정체성과 설명을 뒷받침하며 인기도를 측정하지 않습니다. 기존 59종의 데이터와 등급은 유지했습니다. 현재 분포는 **발견 35 / 보물 22 / 경이 7 / 불가사의 3**으로, 높은 등급일수록 종류가 적습니다.

등급 확률은 **70/23/6/1%**를 유지합니다. 등급 안에서 균등 추첨하므로 개별 명소의 확률은 각각 약 **2% / 1.0455% / 0.8571% / 0.3333%**입니다. 새 항목은 일반 탐험권 뽑기에 포함되며 저장을 읽는 것만으로 지급하지 않습니다. 기존 지급 기록·보유 수량·배치는 유지합니다. 스키마 v4와 최대 육지 318칸도 동일합니다. 새 ID가 담긴 백업은 확장 도감이 포함된 빌드에서 읽어야 합니다.

## 출처와 표현의 범위

좌표는 Wikidata P625에서 가져왔고 항목별 엔티티 URL을 도감에 보관했습니다. 스카이 타워는 표시된 도·분·초를 십진수로 변환했습니다. 소수 여섯 자리로 반올림한 지도 안내용 지점이며 측량 데이터가 아닙니다. 바레인은 보유 명소 마커와 국가별 수집 행으로 표시합니다. 기존 저해상도 국가 경계 데이터에는 작은 육지 형태가 생략되어 있습니다.

쿠웨이트 타워의 UNESCO 출처는 **잠정목록 제출**이며 세계유산 등재를 뜻하지 않습니다. 자료마다 개장 연도가 달라 설명에서는 생략했습니다. 티라나 피라미드는 1988년 건축물을 2023년에 전환한 사례로 설명하며 2023년 신축으로 표현하지 않았습니다. 원래 호자 박물관이었던 맥락도 유지했습니다. 루마니아 의회궁은 차우셰스쿠 시대의 건설 맥락을 담고 논쟁의 여지가 있는 세계 최대·최중량 기록은 사용하지 않았습니다.

그림은 직접 제작한 양식화 벡터이며 사진이나 실측 건축 모형이 아닙니다. 정원 장식은 가상의 해석입니다. 외부 이미지·폰트·실행 시 원격 자산을 추가하지 않았습니다.

## 로컬 검증

빌드·타입 검사·상태/워커 검사를 통과했습니다. 전체 67종 추첨, 장식 142종과 전체 도감 백업 왕복을 포함합니다. 전체 브라우저 검사는 72개 중 71개가 통과했습니다. 실패 1개는 테스트 선택자가 “Oman”을 “Romania” 안에서도 찾는 문제였으며, 정확한 텍스트 비교로 고친 뒤 현대 국가 시나리오 세 개가 재실행에서 모두 통과했습니다. 새 여덟 국가 시나리오는 발견·배치·선물·중복 재료·제작·재로드·한국어 설명과 기존 수집 기록 보존을 확인합니다. 67종 아트 검사와 새 그림 여덟 종의 육안 확인도 완료했습니다.

격리된 브라우저 fixture 검증입니다. 실제 Orca 클릭 검증은 계속 보류합니다. 실제 사용자 저장에 보상을 주입하지 않았으며 실행 승인·푸시·배포를 하지 않았습니다.

최종 독립 실행 번들 검사와 두 플러그인의 `pnpm validate`를 통과했습니다.
