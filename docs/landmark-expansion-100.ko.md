## 땅과 저장 호환성

주소 격자는 40 × 40, 실제 육지는 최대 1,044칸입니다. 처음 12종까지 기존 36→318칸을 그대로 유지하고 13~100종까지 바깥 땅을 연결해 엽니다. 25/50/75/100종에 425/631/837/1,044칸입니다. 기존 576개 주소 및 기존 318개 육지의 전체 속성과 해금 단계를 회귀 검사합니다. 새 좌표는 뒤에 추가하며 기존 호수와 배치를 유지합니다. 음수 좌표도 화면·미니맵·깊이 정렬에 반영했습니다.

현재 저장 스키마 v5는 랜드마크 방향을 저장하고 이전 버전을 읽습니다. 땅 확장은 기존 주소를 유지합니다. 기존 보유 종류가 12종을 넘으면 그만큼 새 땅이 열립니다. 100종과 기본 선물 전체 배치, 1,044칸 바닥을 포함한 백업의 저장·복원과 256 KiB 상한을 검사합니다. 새 항목·외곽 주소가 들어 있는 백업은 이 빌드 또는 이후 호환 버전이 필요합니다. 실제 사용자 저장을 변경하거나 보상을 지급하지 않았습니다.

## 검증

로컬 빌드·타입 검사·상태/워커 검사와 `pnpm validate`를 통과했습니다. 브라우저 전체 실행에서는 85개를 통과했고, 새 전체 섬 검사는 다른 테스트용 건물에 가려진 바닥을 눌러 처음 실패했습니다. 이동할 주변 공간을 비우고 건물 자체를 선택하도록 테스트 배치를 고친 뒤 해당 검사를 Nx로 다시 실행해 통과했습니다. 총 86개 브라우저 항목을 확인했습니다. 새 검사는 육지 1,044칸에 100종을 표시하고, 새 외곽 주소 사이에서 이동하며, 카메라 DOM 유지·저장 복원·390px 한국어 화면의 섬 전체 보기를 확인합니다. 새 33종 전체의 뽑기·배치·장식 제작·재로드·한국어 설명과 SVG 경로·색상 참조 격리도 검사했습니다.

브라우저 테스트 데이터와 로컬 패키지 기준입니다. 실제 Orca 클릭 검증은 사용자의 요청대로 보류합니다. 배포·푸시·실행 승인은 하지 않았습니다.
